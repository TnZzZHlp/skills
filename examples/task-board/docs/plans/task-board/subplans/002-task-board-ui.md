## 目标与范围

实现浏览器看板：创建任务、显示三个状态列、通过选择器修改状态，以及确认后删除。不包含拖拽、标题编辑、身份认证和持久化逻辑。

前置条件：阶段 001 的接口契约可用，且实施已获单独授权。

## 设计

| 拟新增路径 | 职责 |
| --- | --- |
| apps/web/src/main.tsx | 挂载应用，不放置任务业务逻辑 |
| apps/web/src/features/tasks/TaskBoard.tsx | 加载任务状态，协调已确认的数据修改 |
| apps/web/src/features/tasks/TaskForm.tsx | 输入标题，展示创建请求反馈 |
| apps/web/src/features/tasks/TaskCard.tsx | 显示任务、状态选择和删除确认 |
| apps/web/src/lib/task-api.ts | 相对 API 请求，统一网络错误 |
| apps/web/vite.config.ts | 回环地址开发服务器和同源 API 代理 |

使用带标签的原生无障碍控件，分别表达加载、空列表、等待和失败状态。服务端确认成功前，不修改任务显示状态或移除任务。修改请求等待期间防止重复提交。

修改失败时保留最后确认的任务状态和已输入标题。说明可以先刷新核对不确定结果，再手动重试；创建请求失败后不自动重试。

交付物：已集成的本地看板，以及覆盖四个范围内操作的无障碍控件。
