## 目标与范围

收集可复现证据，证明集成应用满足目标。覆盖浏览器流程、重启持久化、写入失败和本地运行边界。不包含单元测试、负载基准测试和云部署。

前置条件：集成应用已存在，实际启动命令已明确，且实施已获单独授权。

## 设计

| 拟新增路径 | 职责 |
| --- | --- |
| e2e/task-board.spec.ts | 浏览器流程自动化和重启持久化检查 |
| e2e/support/local-app.ts | 隔离的服务生命周期与临时数据库管理 |
| package.json | 工具建立后，提供实际验证过的端到端执行方式 |
| docs/validation/task-board.md | 实际结果和可复现的手工失败检查步骤 |

在 003-T01 中选择支持真实浏览器的端到端运行器。断言使用可见标签和任务内容，不依赖脆弱的 CSS 结构。

每次运行使用全新的临时数据库。重启检查期间保留该数据库，服务关闭后再删除。测试配置缺失时，绝不能回退到开发者的真实数据库。

交付物：一个可复现的核心流程测试，以及如实记录的端到端和手工检查结果。
